今回は、有名な事実ではあるが、後方参照を認める正規表現が表す言語は正規言語とは限らないことを示す。

## 後方参照

後方参照とは、キャプチャグループにマッチした文字列を、後続のパターンの中で再び参照する機能である。後方参照を含む正規表現の例を以下に示す。

```regex
^(.)o\1$
```

キャプチャグループ`(.)`は任意の 1 文字にマッチし、その文字をグループ 1 としてキャプチャする。次に文字`o`がマッチし、その後にグループ 1 でキャプチャされた文字列が`\1`によって再びマッチする。すなわち、この正規表現は同じ文字が`o`の前後にある文字列にマッチする。
例えば、`sos`[^ 遭難信号]や`coc`[^ https://github.com/neoclide/coc.nvim]、`bob`[^ Alice にメッセージを送られることで有名]などの文字列が該当する。

具体的な使い方として、簡易的に HTML タグの対応のチェックが考えられる。

```regex
<([A-Za-z][A-Za-z0-9]*)\b[^>]*>.*?</\1>
```

もちろん厳密な仕様に沿った HTML タグの検査はさらに複雑だが、最低限、開始タグと終了タグが同じであることを確認できる。

## 正規言語

正規言語とは、**ある有限オートマトンで認識できる言語**である。たとえば、以下の有限オートマトンは 0 と 1 からなるアルファベット上の文字列のうち、同じ文字が連続するような文字列を認識する。

```automaton
start [shape=point];
q1 [shape=doublecircle];
q2 [shape=doublecircle];

start -> q0;
q0 -> q1 [label="0"];
q0 -> q2 [label="1"];
q1 -> q1 [label="0"];
q1 -> q3 [label="1"];
q3 -> q3 [label="0,1"];
q2 -> q2 [label="1"];
q2 -> q4 [label="0"];
q4 -> q4 [label="0,1"];
```

したがって、そのような文字列の集合（= 言語）は正規言語であると言える。このような正規言語を表現するための手法として、**正規表現**がある。これは、$\cup$（和集合）、$*$（スター演算）、$\circ$（連結）によって正規言語を表現することができる[^ これら 3 つの演算が正規言語に閉じていることは個別に証明できる]。たとえば、上の有限オートマトンと等価な正規表現を以下に示す。

$$
0 \circ 0^* \cup 1 \circ 1^*
$$

正規表現 $R$ で表現できる言語 $L$ は常に正規言語である。すなわち、後方参照付き正規表現が表現できる言語に、正規言語でないものが含まれていればタイトルの命題を証明することができる。

まず、最初に示した後方参照を含む正規表現を見てみよう。

```regex
^(.)o\1$
```

これはアルファベットの個数によって状態数は増えていくものの、有限オートマトンで表現できることがわかる。たとえば、アルファベット $\Sigma = {o, p}$ であるとすると、以下の有限オートマトンで表現できる。

```automaton
start [shape=point];
qg1 [shape=doublecircle];
qg2 [shape=doublecircle];

start->q0;
q0->q1 [label="o"];
q0->q2 [label="p"];
q1->qx [label="p"];
q1->q3 [label="o"];
q3->qg1 [label="o"];
q3->qx [label="p"];
qx->qx [label="o,p"];
q2->q4 [label="o"];
q2->qx [label="p"];
q4->qg2 [label="p"];
q4->qx [label="o"];
qg1->qx [label="o,p"];
qg2->qx [label="o,p"];
```

一方、次のような後方参照付きの正規表現は有限オートマトンでは表現できない。

```regex
^(a*)b\1$
```

直感的には 1 つ目のキャプチャグループでキャプチャされる文字列長を保存しておく手段が有限オートマトンには存在せず、有限状態に落とせないからである。
しかし、残念ながら直感的に無限状態が必要そうに見えても有限オートマトンで表現できる言語も存在する。たとえば、「文字列中に登場する $01$ の個数と $10$ の個数が一致する文字列」による言語である。これを有限オートマトンで表現する方法は読者への課題とするが、直感的に正規言語であるかどうかを区別することは難しい。

ある言語が正規言語であるかどうかを証明する道具として、**ポンピング補題**が存在する。
