# nix

Configuration for applications, hosts, and user space using Nix.

## flakes

Flake output definitions. Defines various system configurations and templates.

## home

User environment configuration via Home Manager. Manages per-user settings.

## hosts

Individual NixOS host configurations. Defines system configuration for each
host.

## lib

Common library functions. Provides reusable functions for tasks like Kubernetes
cluster setup.

## modules

Custom modules for NixOS and Home Manager.

## overlays

Nix package overlays. Extensions and customizations of existing packages.

## packages

Custom package definitions. Packages custom tools and scripts.

## profiles

Reusable configuration profiles. Groups common configurations for nixvim, tmux,
etc.

## templates

Project templates. Provides scaffolding for new projects.
