# nix

Nix によるアプリケーションやホスト、ユーザ空間に対する設定。

## flakes

Flake の出力定義。各種システム設定やテンプレートなどを定義している。

## home

Home Manager によるユーザー環境の設定。ユーザーごとの設定を管理。

## hosts

NixOS ホストの個別設定。ホストごとのシステム構成を定義。

## lib

共通ライブラリ関数。Kubernetes クラスタ構築などの再利用可能な関数を提供。

## modules

NixOS および Home Manager に対するカスタムモジュール。

## overlays

Nix パッケージのオーバーレイ。既存パッケージの拡張やカスタマイズ。

## packages

カスタムパッケージ定義。独自のツールやスクリプトをパッケージ化。

## profiles

再利用可能な設定プロファイル。nixvim、tmux などの共通設定をまとめる。

## templates

プロジェクトテンプレート。新規プロジェクトの雛形を提供。
